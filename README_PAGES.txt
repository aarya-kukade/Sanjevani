## 🎨 Customization Tips

### Change Colors
Edit `:root` in `home-styles.css`:
```css
--primary: #0a9396;      /* Change teal */
--secondary: #00d4d4;    /* Change cyan */
--accent: #10a688;       /* Change green */
```
